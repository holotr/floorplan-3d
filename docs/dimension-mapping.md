## 官方外框与净尺寸之间的配准

官方整体外框采用 **10700 × 11550**，上方参考跨度 9300，厨房参考宽 2600，上部进深 3100，双卫分段 1750 / 1800，底部窗台区域参考进深 500。页面以“图”区分官方参考，以“≈”区分估算，实测净尺寸不加前缀。

- 下部横向闭合：153 + **3365** + 150 + **3765** + 150 + **2964** + 153 = **10700**。
- 上部净深：151 + **2874** + 75 = **3100**；厨房净深暂与相邻房间对齐，不能据此称为厨卫实测。
- 主卧纵向配准：3100 + 1750 + 1800 + 79 + **4771** + 50 = **11550**。
- 次卧主矩形净深：11500 − 7617 = **3883**；官方外侧退台 y=7300，至净面 y=7617 的 317 暂作构造预留。

上述 151、153、75、79、317、50 是在外框与净尺寸之间分配的**配准假设**，不能作为现场墙厚或结构做法。常用内隔墙暂取 150、家政/储物部分隔墙暂取 100；上方东外墙暂取 200。底部 50 仅为显示用窗框线；官方 500 窗台区域包含在房间下端内，不另增面积。

客卫按官方关系恢复为与上方长辈房齐边的内凹区域，左侧室外凹口不铺室内地面。主卫向左延至下部外墙；主卫门通主卧，客卫门通客餐厅。厨房烟道暂取 600 × 400，厨房净开间暂为 2300，均为估算。
