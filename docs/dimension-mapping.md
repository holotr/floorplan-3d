## 推定值与闭合方法

两张图都没有完整逐段墙厚和门窗洞口表。本版以 150 为大部分墙厚，理由是两条独立的实测链同时闭合：

- 横向：150 + 3365 + 150 + 3765 + 150 + 2964 + 150 = **10694**。
- 纵向：150 + 2874 + 150 + 1412 + 150 + 1436 + 150 + 4771 + 150 = **11243**。

右侧家政/储物北墙和两小间分隔取 100；由此 1793 / 958 / 885 / 3883 四段及转折保持兼容。上方三间外包宽 8192；西外皮 x=641，东外皮 x=8833，玄关外皮 x=9328。未测的门窗定位按图形比例及相邻关系推定，不能理解为现场逐点复测。

- 红框是主卫东墙外侧的餐边柜，按现有间隙暂放 **1400 × 500** 的可编辑柜体，中心为 (3412, 5454)，朝向餐厅。柜体不作为墙体或独立房间。

- 新墙追加到数组尾部，既有墙索引保持；现有布局只补入一次餐边柜，保留已编辑家具、房名、材料、测量及拆墙记录。

## 存档与验证

新方案带 `planId: measured-10694x11243-v1`，使用独立本地存储键，同一户型的此次修正使用 `layoutRevision: 2` 迁移。旧项目的家具和墙索引不会自动进入新户型，旧 JSON 导入会提示户型不匹配；本户型导出 JSON 可以继续导入。

```sh
node --test tests/floorplan.test.cjs
python3 -m http.server 8000 --bind 127.0.0.1
```

测试核对外包尺寸、净宽深、已标注尺寸、主要面积、门窗洞口无墙体遮挡、房间连通、房间互不重叠且不穿墙、默认家具范围、存档隔离、不同宽高比下全屋取景。浏览器核对 2D/3D、房间视角、剖切/全高、漫游、家具编辑与撤销、语言切换及导入导出。
